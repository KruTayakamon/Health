# Health — ผู้ช่วยลดน้ำหนักส่วนตัวของครูทยากมล

ระบบ "ทีม agent ลดน้ำหนัก" ระยะ 1 — ใช้ผ่าน Claude Code ในรีโปนี้

## เริ่มอ่านที่นี่
- 📋 **[แผนส่วนตัว 12 สัปดาห์แรก](docs/plan-phase1.md)** — ตัวเลขของคุณ มื้ออาหาร ยิม กฎชาบู ช่วงหยุดยา สัปดาห์แรก
- 📄 [ข้อเสนอการออกแบบระบบ](docs/weight-loss-agent-team-design.md) — โครงสร้าง agent 7 ตัว และแผน 3 ระยะ

## โครงสร้าง
```
CLAUDE.md            บทโค้ชหลัก (orchestrator) — Claude Code อ่านอัตโนมัติ
profile.yaml         โปรไฟล์ เป้าหมาย งบ ข้อจำกัดทางการแพทย์
agents/              บท agent 8 ตัว (อาหาร วางแผน ออกกำลัง ความก้าวหน้า พฤติกรรม เพื่อนร่วมทาง ความปลอดภัย คลังข้อมูล)
data/thai-foods.csv  ฐานข้อมูลอาหารไทย/ญี่ปุ่น/7-11/บุฟเฟ่ต์ ~85 รายการ (เพิ่มได้)
logs/                บันทึกน้ำหนัก อาหาร ออกกำลัง เช็กอินรายวัน รายงานสัปดาห์ สมุดหลักฐาน (wins.md) บันทึก 3 บรรทัด (journal.md)
scripts/weekly.py    คำนวณสรุปสัปดาห์ (ค่าเฉลี่ย 7 วัน คาด vs จริง คะแนนพฤติกรรม)
.claude/skills/      คำสั่งลัด
```

## คำสั่งลัดที่ใช้ทุกวัน
| คำสั่ง | ใช้เมื่อ |
|---|---|
| `/weigh 114.6` | ชั่งตอนเช้า |
| `/eat กะเพราหมูสับ ข้าวครึ่งจาน` | ทุกมื้อ (หรือถาม "เย็นนี้กินอะไรดี") |
| `/workout เวท 40 นาที` | หลังออกกำลัง |
| `/day-review` | ก่อนนอน |
| `/week-review` | อาทิตย์เย็น |
| `/coach ...` | คุยอะไรก็ได้เรื่องแผน |
| `/talk ...` | ท้อ อาย เหงา อยากเลิก หรือแค่อยากมีคนฟัง — ไม่มีตัวเลข |

## สรุปสัปดาห์ด้วยมือ
```bash
python3 scripts/weekly.py            # สัปดาห์ที่จบวันนี้
python3 scripts/weekly.py 2026-11-09 # ระบุวันสุดท้ายของสัปดาห์
```

> ระบบนี้ไม่ใช่คำแนะนำทางการแพทย์ เรื่องยา (Mounjaro, metformin) และ PCOS ให้คุยกับแพทย์เสมอ
