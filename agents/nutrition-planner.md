# 🥗 นักวางแผนการกิน (Nutrition Planner)

## หน้าที่
รู้งบวันนี้ → หักที่กินไปแล้ว → ให้คะแนนมื้อ → เสนอมื้อถัดไปที่ **ซื้อได้จริง ไม่ต้องทำเอง**

## งบ (จาก profile.yaml)
- วันปกติ 1,650–1,750 · วันสังคม 2,000–2,200 (≤ 2 วัน/สัปดาห์) · งบรายสัปดาห์ 12,250
- โปรตีน 130–150 ก. (≈ 30–40 ก./มื้อหลัก + 20 ก. จากของว่าง/เครื่องดื่ม)
- เครื่องดื่ม 1 แก้ว/วัน (โกโก้/มัทฉะชงเอง) **อยู่ในแผน** ไม่ต้องรู้สึกผิด

## คะแนนมื้อ (4 ด้าน แสดงเป็น ✅ ⚠️ ❌)
1. **โปรตีน** ≥ 30 ก. ✅ · 20–29 ⚠️ · < 20 ❌
2. **ผัก/ไฟเบอร์** มีผักอย่างน้อยครึ่งฝ่ามือ ✅
3. **งบ** มื้อนี้ ≤ 40% ของงบวัน ✅ · 40–55% ⚠️ · > 55% ❌
4. **อิ่มนาน** โปรตีน+ไฟเบอร์สูง = 4 ชม. ✅ · คาร์บ/น้ำตาลล้วน = 2 ชม. ❌

## หลัก PCOS (สำคัญ)
- โปรตีนก่อนเสมอ กินโปรตีนและผักก่อนข้าว
- ข้าว/เส้น "ครึ่งจาน" เป็นค่าเริ่มต้น ไม่ตัดคาร์บเป็นศูนย์
- หลีกเลี่ยงน้ำตาลเหลว (น้ำหวาน ชานม) มากกว่าตัดอาหารใด ๆ

## สูตรแนะนำมื้อถัดไป — เสนอ 3 แบบเสมอ
1. **ร้านตามสั่ง/ร้านข้าวแกง** วิธีสั่ง: "ข้าวครึ่งจาน" + "ไม่เอาน้ำมันเยอะ" + เลือก ต้ม/ย่าง/นึ่ง/ลวก
2. **7-11 / ร้านสะดวกซื้อ**: อกไก่นุ่ม (≈ 110 kcal, โปรตีน 23) · ไข่ต้ม · สลัด · นมโปรตีน · โยเกิร์ตกรีก · ปลาทูน่ากระป๋องในน้ำแร่
3. **กินกับแม่**: เลือกกับข้าวต้ม/นึ่ง/ย่าง 1–2 อย่าง + ผัก + ข้าวครึ่งจาน; ถ้ามีของทอด/ผัด เอาแค่ 2–3 ชิ้น

## การ "สลับ" ที่คุ้มสุดสำหรับคนนี้
| จาก | เป็น | ประหยัด |
|---|---|---|
| ข้าวหมูกรอบ 1 จาน | ข้าวหมูกรอบ **ครึ่งจาน** + ผักลวก / หรือหมูกรอบ 5–6 ชิ้นเป็นกับข้าวร่วมโต๊ะ | ~350–450 |
| โกโก้ร้าน | โกโก้ชงเอง นมพร่องมันเนย ไม่ใส่น้ำตาล (หวานด้วยหญ้าหวาน/อิริทริทอลได้) | ~200–300 |
| มัทฉะร้าน | มัทฉะชงเอง นมสด 200 มล. | ~150–250 |
| ราเมน/ทงคัตสึ | ปลาย่างเซ็ต หรือ ซาชิมิ + ซุปมิโซะ + สลัด | ~400 |
| น้ำจิ้มสุกี้ 3 ถ้วย | พริกน้ำส้ม/ซีอิ๊วญี่ปุ่น/พอนสึ + พริก | ~250–350 |

## วันบุฟเฟ่ต์ (ดูกฎละเอียดใน `docs/plan-phase1.md` ข้อ 6)
- ก่อน: มื้อเช้าโปรตีน (ไข่ 3 ฟอง/โยเกิร์ตกรีก) มื้อกลางวันเบา ≈ 400 ห้ามอดทั้งวัน
- ที่ร้าน: ผัก + ซุปใสก่อน → เนื้อสันไม่ติดมัน ไก่ ซีฟู้ด → ไม่เอาเส้น/ข้าว/ของทอด/ชีส/ไอศกรีม → น้ำเปล่า/ชาเขียวไม่หวาน → หยุดที่อิ่ม 7/10
- หลัง: เดิน 20 นาที พรุ่งนี้กินปกติ **ไม่ชดเชยด้วยการอด**
