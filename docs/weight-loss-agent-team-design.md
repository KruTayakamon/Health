# ข้อเสนอการออกแบบ: ทีม Agent ผู้ช่วยลดน้ำหนักส่วนตัว

> สถานะ: **ร่างข้อเสนอ (รอการอนุมัติ)** — ยังไม่ได้สร้างระบบจริง
> วันที่: 3 พ.ย. 2026
> เจ้าของ: ครูทยกมล

---

## 0. สรุปสำหรับคนรีบอ่าน

| หัวข้อ | ข้อเสนอ |
|---|---|
| โจทย์ | น้ำหนัก 115 กก. กำลังจะหยุด GLP-1 แล้วเปลี่ยนมาคุมอาหาร + ออกกำลังกาย ต้องการ "ผู้ช่วยฉลาด" ที่วิเคราะห์อาหาร แนะนำมื้อถัดไป ประเมินหลังออกกำลังกาย ตั้งเป้ารายสัปดาห์ และวินิจฉัยเมื่อน้ำหนักไม่ลด |
| รูปแบบ | **1 โค้ชหลัก + 7 agent ผู้เชี่ยวชาญ** ทำงานร่วมกัน คุณคุยกับโค้ชคนเดียว โค้ชส่งงานไปหาผู้เชี่ยวชาญเบื้องหลัง (เพิ่ม 🤝 เพื่อนร่วมทาง ดูแลจิตใจ — 3 พ.ย.) |
| เป้าที่ปลอดภัย | ลด **0.5–1.0 กก./สัปดาห์** (ประมาณ 0.5–0.9% ของน้ำหนักตัว) 2–3 สัปดาห์แรกอาจลดเร็วกว่านี้เพราะน้ำในตัว |
| จุดเสี่ยงที่สุด | **ช่วง 2–8 สัปดาห์หลังหยุด GLP-1** ความหิวจะกลับมาแรง งานวิจัยพบว่าคนส่วนใหญ่น้ำหนักกลับขึ้นราว 2/3 ภายใน 1 ปีถ้าไม่มีระบบรองรับ ระบบนี้ออกแบบมาเพื่ออุดช่องนี้โดยเฉพาะ |
| แผนสร้าง | 3 ระยะ — ระยะ 1 ใช้ได้ภายในสัปดาห์เดียว (ไม่ต้องเขียนโปรแกรม) ระยะ 2 เป็น LINE/เว็บแอป ระยะ 3 ถ่ายรูปอาหารแล้ววิเคราะห์อัตโนมัติ |
| ต้องการจากคุณ | ส่วนสูง อายุ เพศ ระดับกิจกรรม ยา GLP-1 ที่ใช้และแผนหยุดจากแพทย์ โรคประจำตัว (ดูข้อ 9) |

> ⚠️ **ข้อควรระวังสำคัญ:** การหยุด GLP-1 ควรปรึกษาแพทย์ผู้สั่งยาก่อน (บางกรณีแพทย์จะแนะนำให้ค่อย ๆ ลดโดส) ระบบนี้เป็นเครื่องมือช่วยติดตามและวางแผน **ไม่ใช่คำแนะนำทางการแพทย์** และจะมี agent ด้านความปลอดภัยคอยเตือนให้กลับไปหาแพทย์เมื่อพบสัญญาณผิดปกติ

## 1. เป้าหมายของระบบ (สิ่งที่ผู้ช่วยต้องทำได้)

จากที่คุณบอก แยกออกมาเป็นความสามารถ 6 ข้อ:

1. **วิเคราะห์อาหารที่กิน** — บอกแคลอรี่ โปรตีน คาร์บ ไขมัน ไฟเบอร์ จากข้อความ (หรือรูปในระยะ 3)
2. **ประเมินมื้อที่กิน** — ดีหรือยัง ควรปรับตรงไหน (ไม่ใช่แค่บอกตัวเลข)
3. **แนะนำมื้อถัดไป** — ตามงบแคลอรี่ที่เหลือ โปรตีนที่ยังขาด และสิ่งที่หาซื้อง่ายในไทย
4. **ประเมินหลังออกกำลังกาย** — ควรกินเพิ่มอะไร หรือพอแค่นี้
5. **ตั้งเป้ารายสัปดาห์** — ควรลดได้เท่าไหร่ และเทียบกับของจริง
6. **วินิจฉัยเมื่อไม่ลดตามเกณฑ์** — ผิดตรงไหน แก้อย่างไร (ด้วยข้อมูล ไม่ใช่เดา)

และความสามารถที่คุณไม่ได้ขอแต่ **จำเป็น** สำหรับกรณีหยุด GLP-1:

7. **รับมือความหิวที่กลับมา** — วางแผนล่วงหน้าตั้งแต่ก่อนหยุดยา
8. **ความปลอดภัย** — เตือนเมื่อลดเร็วเกิน กินน้อยเกิน หรือมีอาการผิดปกติ

## 2. โครงสร้างทีม Agent

```
                    ┌──────────────────────────┐
     คุณ  ◄───────► │   🧭 โค้ชหลัก (Orchestrator)  │
                    │   คุยกับคุณคนเดียว จำบริบททั้งหมด │
                    └────────────┬─────────────┘
                                 │ มอบงานเบื้องหลัง
   ┌──────────┬──────────┬───────┼───────┬──────────┬──────────┐
   ▼          ▼          ▼       ▼       ▼          ▼          ▼
🍚 นัก      🥗 นักวาง   🏃 นัก   📈 นัก   🧠 โค้ช    🛡️ ผู้ดูแล   🗄️ คลัง
วิเคราะห์   แผนการกิน   วิเคราะห์ วิเคราะห์ พฤติกรรม  ความ      ข้อมูล
อาหาร                  การออก   ความ              ปลอดภัย   (Memory)
                       กำลังกาย ก้าวหน้า
```

### 2.1 🧭 โค้ชหลัก (Head Coach / Orchestrator)
- **หน้าที่:** เป็นหน้าด่านคนเดียวที่คุณคุยด้วย รับข้อความ → ตัดสินว่าต้องเรียกใครบ้าง → รวมคำตอบให้สั้น ตรงประเด็น ไม่เทศนา
- **บุคลิก:** ตรงไปตรงมา ให้กำลังใจแบบไม่โลกสวย ใช้ตัวเลขประกอบทุกครั้ง
- **กฎ:** ทุกคำตอบต้องมี "สิ่งที่ควรทำต่อ 1 อย่าง" เสมอ ไม่ปล่อยให้คุณต้องตีความเอง
- **ตัวอย่างงาน:** คุณพิมพ์ "กินข้าวมันไก่ 1 จาน กับน้ำเย็น" → โค้ชเรียกนักวิเคราะห์อาหาร + นักวางแผน แล้วตอบรวมในข้อความเดียว

### 2.2 🍚 นักวิเคราะห์อาหาร (Food Analyst)
- **หน้าที่:** แปลงสิ่งที่กินเป็นตัวเลข — แคลอรี่, โปรตีน, คาร์บ, ไขมัน, ไฟเบอร์, โซเดียม
- **ความรู้พิเศษ:** ฐานข้อมูล **อาหารไทย** (ข้าวมันไก่, กะเพรา, ส้มตำ, ก๋วยเตี๋ยว, ขนมครก, ชานมไข่มุก ฯลฯ) พร้อมขนาดจานมาตรฐานร้านตามสั่ง/ร้านสะดวกซื้อ
- **กฎสำคัญ:** บอก **ช่วง** ไม่ใช่ตัวเลขเดียว (เช่น "550–700 กิโลแคลอรี่") และบอกระดับความมั่นใจ เพราะอาหารตามสั่งน้ำมันไม่แน่นอน
- **ถามกลับเมื่อจำเป็น:** จานเล็ก/ใหญ่? มีน้ำจิ้ม? หนังไก่? ซดน้ำซุปหมดไหม?
- **ผลลัพธ์:** รายการอาหาร + ตัวเลข + ความมั่นใจ (สูง/กลาง/ต่ำ) + "ตัวการหลัก" ของแคลอรี่ในจานนั้น

### 2.3 🥗 นักวางแผนการกิน (Nutrition Planner)
- **หน้าที่:** รู้งบประจำวันของคุณ (แคลอรี่ + โปรตีน + ไฟเบอร์) → คำนวณว่าเหลือเท่าไหร่ → แนะนำมื้อถัดไปที่ **ทำได้จริง**
- **หลักการประเมินมื้อ (ให้คะแนน 4 ด้าน):**
  1. โปรตีนพอไหม (เป้า ≥ 25–40 กรัม/มื้อหลัก)
  2. ไฟเบอร์/ผักพอไหม
  3. แคลอรี่อยู่ในงบไหม
  4. ความอิ่ม (จะหิวอีกในกี่ชั่วโมง?)
- **การแนะนำ:** เสนอ 2–3 ตัวเลือก มีทั้ง "ทำเอง" และ "ซื้อหน้าปากซอย/7-11" และวิธี **สลับ** (swap) เช่น "ข้าวมันไก่ → สั่งไก่ต้มไม่เอาหนัง ข้าวครึ่งจาน เพิ่มแตงกวา ลดได้ ~200 กิโลแคลอรี่"
- **ปรับตามช่วงหยุด GLP-1:** เน้นโปรตีนก่อนทุกมื้อ อาหารปริมาตรมากแคลอรี่ต่ำ (volume eating) กำหนดเวลามื้อชัดเจน

### 2.4 🏃 นักวิเคราะห์การออกกำลังกาย (Exercise Analyst)
- **หน้าที่:** บันทึกการออกกำลังกาย → ประเมินพลังงานที่ใช้ (ใช้ค่า MET × น้ำหนัก × เวลา) → ตัดสิน "ควรกินเพิ่มหรือพอ"
- **กฎการตัดสินใจหลังออกกำลังกาย:**

| สถานการณ์ | คำแนะนำ |
|---|---|
| ออกกำลังเบา < 45 นาที (เดิน, ยืดเหยียด) | **ไม่ต้องกินเพิ่ม** ดื่มน้ำพอ |
| คาร์ดิโอ 45–60 นาที | กินตามแผนปกติ ไม่ "กินคืน" แคลอรี่ที่เผา |
| เวทเทรนนิ่ง / ออกกำลังหนัก ≥ 45 นาที | **โปรตีน 25–40 กรัม ภายใน 2 ชม.** (ไข่ 3 ฟอง / อกไก่ 120 ก. / นมถั่วเหลืองโปรตีนสูง) ถ้ายังมีงบเหลือ |
| ออกกำลังนาน > 90 นาที | เติมคาร์บ + โปรตีน และนับเป็นแคลอรี่เพิ่มได้ **ครึ่งหนึ่ง** ของที่ประเมิน (เพราะอุปกรณ์มักประเมินสูงเกินจริง) |
| ออกกำลังตอนที่กินครบงบแล้ว | ให้พอ ถ้าหิวมากจริง → โปรตีนล้วน ≤ 150 กิโลแคลอรี่ |

- **หลักการ:** การออกกำลังกายสร้าง deficit ได้น้อยกว่าที่คนคิดมาก (เดิน 30 นาทีที่ 115 กก. ≈ 180–220 กิโลแคลอรี่ = ชานมแก้วเดียว) หน้าที่หลักของการออกกำลังคือ **รักษามวลกล้ามเนื้อ** ระหว่างลดน้ำหนัก ไม่ใช่เผาแคลอรี่

### 2.5 📈 นักวิเคราะห์ความก้าวหน้า (Progress Analyst)
- **หน้าที่:** ดูตัวเลขทั้งหมดรายสัปดาห์ → เทียบ "ควรลดได้" กับ "ลดจริง" → **วินิจฉัย** เมื่อไม่ตรง
- **วิธีชั่งที่ถูกต้อง:** ชั่งทุกเช้าหลังเข้าห้องน้ำ ก่อนกิน แต่ **ดูค่าเฉลี่ย 7 วัน** เท่านั้น ไม่ดูรายวัน (น้ำหนักแกว่งวันละ 1–2 กก. จากน้ำ)
- **สูตรเป้ารายสัปดาห์:**
  - น้ำหนักที่ควรลด (กก.) ≈ (deficit ต่อวัน × 7) ÷ 7,700
  - เช่น deficit 600 กิโลแคลอรี่/วัน → ≈ 0.55 กก./สัปดาห์ (จากไขมันล้วน)
  - สัปดาห์ 1–2 มักลดมากกว่านี้ (น้ำ + ไกลโคเจน) อย่าดีใจเกิน และอย่าตกใจตอนสัปดาห์ 3 ที่ชะลอ
- **ขั้นตอนวินิจฉัยเมื่อไม่ลด (Decision Tree)** — ดูข้อ 5

### 2.6 🧠 โค้ชพฤติกรรม (Behavior & Habit Coach)
- **หน้าที่:** ดูแลสิ่งที่ตัวเลขไม่บอก — ความหิว อารมณ์ การนอน ความเครียด รูปแบบการกินวันหยุด
- **เน้นช่วงหยุด GLP-1:**
  - สัปดาห์ 0 (ก่อนหยุด): ซ้อมกินแบบใหม่ขณะยังมียาช่วย
  - สัปดาห์ 1–2: ความหิวเริ่มกลับ → เพิ่มโปรตีน/ไฟเบอร์ ยังไม่เพิ่มแคลอรี่
  - สัปดาห์ 3–8: ช่วงอันตรายสุด → เช็กอินทุกวัน วางแผน "ถ้าหิวตอน 4 ทุ่มจะกินอะไร" ไว้ล่วงหน้า
- **เครื่องมือ:** บันทึกระดับความหิว 1–10 ก่อนและหลังมื้อ หาตัวกระตุ้น (trigger) การกินที่ไม่ใช่ความหิว
- **ไม่ทำ:** ไม่ตำหนิ ไม่ใช้คำว่า "โกง" (cheat) ทุกมื้อเป็นข้อมูล

### 2.7 🛡️ ผู้ดูแลความปลอดภัย (Safety Guardian)
- **หน้าที่:** ตรวจทุกคำแนะนำก่อนถึงคุณ และเตือนให้พบแพทย์เมื่อพบสัญญาณ
- **เส้นแดงที่จะหยุดและเตือน:**
  - แคลอรี่ต่ำกว่า **1,200 (หญิง) / 1,500 (ชาย)** ต่อวันติดกันหลายวัน
  - ลดเร็วกว่า **1.5% น้ำหนักตัว/สัปดาห์** หลังสัปดาห์ที่ 2
  - อาการ: เวียนหัว ใจสั่น เป็นลม ผมร่วงมาก ประจำเดือนผิดปกติ นอนไม่หลับรุนแรง
  - อาการถอนยา GLP-1 ที่รุนแรง หรือน้ำตาลในเลือดผิดปกติ (ถ้ามีเบาหวาน)
  - รูปแบบการกินที่เข้าข่ายผิดปกติ (อดอาหารเพื่อชดเชย กินแล้วรู้สึกผิดรุนแรง)
- **กฎตายตัว:** ไม่แนะนำยา อาหารเสริมลดน้ำหนัก หรือ fasting ยาวเกิน 16 ชม. โดยไม่มีแพทย์ดูแล

### 2.8 🤝 เพื่อนร่วมทาง (Companion / Inner-Care) — เพิ่มตามคำขอ
- **หน้าที่:** ดูแล *คน* ไม่ใช่ *ตัวเลข* — ความอาย ความบอบช้ำ ความเหงา การไม่กล้าบอกใคร ทำงาน **เฉพาะเมื่อเรียก `/talk`** (ผู้ใช้เลือกให้ไม่ขึ้นมาเองตลอด) ยกเว้นเส้นแดงความปลอดภัย
- **กฎ:** คำตอบแรกไม่มีตัวเลข ไม่มีแผน ฟังก่อน ใช้ *ข้อเท็จจริง* แทนคำปลอบ (เคยลดถึง 92 / พยายามครั้งที่ 5 คือหลักฐานของการไม่ยอมแพ้) เคารพการ "ลดเงียบ ๆ" เป็นแผนหลัก ไม่ใช่แผนสำรอง
- **เครื่องมือ:** สมุดหลักฐาน `logs/wins.md` (inspiration จากตัวเธอเอง) · บันทึก 3 บรรทัดก่อนนอน · จดหมายรายสัปดาห์ · โปรโตคอลวันที่แย่ (ปิดตัวเลข เสนอขั้นต่ำสุด 1 อย่าง พรุ่งนี้เริ่มใหม่ไม่มีหนี้) · คำถาม "ครูจะพูดกับนักเรียนที่สอบตก 3 ครั้งว่าอะไร"
- **เส้นแดง:** อาการซึมเศร้าต่อเนื่อง ≥ 2 สัปดาห์ / ความคิดไม่อยากอยู่ / กินแบบควบคุมไม่ได้ซ้ำ ๆ → ส่งต่อสายด่วน 1323 และนักจิตวิทยา/จิตแพทย์ด้วยความอบอุ่น พูดชัดว่าตัวเองเป็น AI ไม่ใช่นักบำบัด
- รายละเอียดเต็ม: `agents/companion.md`

### 2.9 🗄️ คลังข้อมูล (Memory / Data Store)
- เก็บโปรไฟล์ บันทึกน้ำหนัก อาหาร การออกกำลังกาย การนอน ความหิว และรายงานสัปดาห์
- ทุก agent อ่าน/เขียนที่เดียวกัน → โค้ชจำได้ว่าเมื่อวานคุณกินอะไร สัปดาห์ก่อนเกิดอะไร

## 4. การทำงานในชีวิตจริง (Flows)

### 4.1 ทุกวัน

| เวลา | คุณทำ | ระบบทำ |
|---|---|---|
| เช้า | ชั่งน้ำหนัก พิมพ์ "114.6" | บันทึก คำนวณค่าเฉลี่ย 7 วัน บอกงบวันนี้ |
| ทุกมื้อ | พิมพ์สิ่งที่กิน (หรือถ่ายรูปในระยะ 3) | วิเคราะห์ → ให้คะแนนมื้อ → บอกงบที่เหลือ → แนะนำมื้อถัดไป 2–3 ทางเลือก |
| หลังออกกำลัง | พิมพ์ "เดินเร็ว 40 นาที" | ประเมินพลังงาน → ตัดสินกินเพิ่ม/พอ |
| ก่อนนอน | ตอบ 3 คำถาม: นอนกี่ชม. หิวแค่ไหน เครียดไหม | สรุปวัน 3 บรรทัด + สิ่งที่ควรทำพรุ่งนี้ 1 อย่าง |

**ตัวอย่างบทสนทนา**

> **คุณ:** กินกะเพราหมูสับไข่ดาว 1 จาน จากร้านตามสั่ง
>
> **โค้ช:** 🍚 ประมาณ **650–800 กิโลแคลอรี่** (มั่นใจกลาง — น้ำมันร้านตามสั่งแกว่งมาก) โปรตีน ~32 ก. ไฟเบอร์ต่ำ
> **คะแนนมื้อ:** โปรตีน ✅ | ผัก ❌ | งบ ⚠️ ใช้ไป 40% ของวัน | อิ่ม ~3 ชม.
> **ปรับครั้งหน้า:** สั่ง "ข้าวน้อย ไม่เอาน้ำมันเยอะ" + เพิ่มผักลวก ลดได้ ~200
> **เหลืองบวันนี้:** ~1,050 กิโลแคลอรี่ / โปรตีนยังขาด ~95 ก.
> **มื้อเย็นแนะนำ:** (1) สุกี้น้ำไม่ใส่วุ้นเส้น เพิ่มไก่ (2) ปลานึ่งมะนาว + ผักต้ม + ข้าวครึ่งจาน (3) 7-11: อกไก่นุ่ม 2 ซอง + สลัดผัก

> **คุณ:** เพิ่งเดินเร็ว 45 นาที
>
> **โค้ช:** 🏃 เผาไปราว **250–300 กิโลแคลอรี่** (ที่ 115 กก.) ดีมาก
> **ตัดสิน:** วันนี้กินไป 1,750 แล้ว **พอแค่นี้** ไม่ต้องกินเพิ่ม ดื่มน้ำ 1–2 แก้ว ถ้าหิวจริงภายใน 1 ชม. → ไข่ต้ม 2 ฟอง (140 กิโลแคลอรี่ โปรตีน 12 ก.)

### 4.2 ทุกสัปดาห์ (วันอาทิตย์เย็น)

นักวิเคราะห์ความก้าวหน้าสรุป:
1. ค่าเฉลี่ยน้ำหนัก 7 วันนี้ vs สัปดาห์ก่อน
2. ลดได้จริง vs ควรลดได้
3. % วันที่บันทึกครบ (adherence)
4. ค่าเฉลี่ยแคลอรี่ โปรตีน การนอน ก้าว
5. **วินิจฉัย** ถ้าไม่ตรงเป้า (ข้อ 5)
6. ปรับงบสัปดาห์หน้า (ถ้าจำเป็น) + เป้าพฤติกรรม 1–2 ข้อ

## 5. เมื่อน้ำหนักไม่ลดตามเกณฑ์ — ลำดับการวินิจฉัย

ระบบจะเช็กตามลำดับนี้ **ก่อน** จะสรุปว่า "ต้องกินน้อยลง" เพราะส่วนใหญ่ปัญหาไม่ได้อยู่ที่งบ:

```
น้ำหนักเฉลี่ย 7 วัน ไม่ลด หรือลด < 50% ของเป้า
│
├─ 1. บันทึกครบไหม?  (< 80% ของมื้อ) ──────────► สาเหตุอันดับ 1: ของที่ไม่ได้บันทึก
│                                                   (น้ำหวาน ของว่าง ชิม น้ำมันปรุง) งานวิจัยพบคนประเมินต่ำกว่าจริง 20–40%
├─ 2. ความมั่นใจของการประเมินต่ำหลายมื้อ? ────────► เปลี่ยนไปกินของที่นับง่ายขึ้น 1 สัปดาห์เพื่อ "สอบเทียบ"
├─ 3. มีเหตุน้ำคั่งไหม?
│     - เริ่มเวทเทรนนิ่งใหม่ (กล้ามเนื้ออักเสบ เก็บน้ำ)
│     - โซเดียม/คาร์บสูงวันก่อนชั่ง
│     - ช่วงก่อนประจำเดือน (บวกได้ 1–2 กก.)
│     - นอนน้อย / เครียด (คอร์ติซอล) ────────────► รอ 1 สัปดาห์ ยังไม่ปรับงบ
├─ 4. นอน < 6 ชม. เกินครึ่งสัปดาห์? ─────────────► แก้การนอนก่อนแก้อาหาร (นอนน้อย = หิวมากขึ้น กินมากขึ้น)
├─ 5. รูปแบบวันหยุด? (ศุกร์–อาทิตย์ กินเกิน) ───────► 2 วันเกินวันละ 1,000 = ลบ deficit ทั้งสัปดาห์
├─ 6. ก้าว/กิจกรรมนอกการออกกำลังลดลง? ───────────► เหนื่อยจากคุมอาหาร → ขยับน้อยลงโดยไม่รู้ตัว (NEAT ลด)
├─ 7. ความหิวหลังหยุด GLP-1 ทำให้พอร์ชันค่อย ๆ โตขึ้น? ─► ย้อนดูขนาดจาน 2 สัปดาห์
└─ 8. ทุกข้อผ่าน และ ≥ 3 สัปดาห์ติด adherence ≥ 90% ──► ร่างกายปรับตัว (TDEE ลดจริง) → ลดงบ 100–150 กิโลแคลอรี่
                                                       หรือเพิ่มเดิน 2,000 ก้าว/วัน และ **ปรึกษาแพทย์** หากยังนิ่ง
```

**ผลลัพธ์ที่คุณจะได้:** ไม่ใช่ "คุณกินเยอะไป" แต่เป็น "สัปดาห์นี้คุณบันทึกครบแค่ 60% และ 3 วันนอนต่ำกว่า 5 ชม. ตัวเลขยังไม่น่าเชื่อถือพอจะปรับงบ สัปดาห์หน้าเป้าคือบันทึกครบ 90% และนอน ≥ 6.5 ชม."

  - ฐานข้อมูลอาหารไทย (`data/thai-foods.csv`) ~200 รายการที่คุณกินบ่อย
  - บันทึกเป็นไฟล์ (`logs/weight.csv`, `logs/food.jsonl`, `logs/exercise.jsonl`)
  - คำสั่งลัด: `/กิน`, `/ชั่ง`, `/ออกกำลัง`, `/สรุปวัน`, `/สรุปสัปดาห์`
- ข้อดี: เริ่มได้ทันที ปรับแก้ง่าย ทุกอย่างอยู่ใน Git

- กราฟน้ำหนักเฉลี่ย 7 วัน

## 9. สิ่งที่ต้องการจากคุณเพื่อเริ่มสร้าง

กรุณาตอบเท่าที่สะดวก (ข้อ 1–4 จำเป็นต่อการคำนวณงบ):

1. **ส่วนสูง** (ซม.)
2. **อายุ**
3. **เพศ**
4. **ระดับกิจกรรมปัจจุบัน** — นั่งเป็นหลัก / เดินบ้าง (สอน ยืน) / ออกกำลังอยู่แล้วกี่วัน
5. **ยา GLP-1** — ชื่อยา โดสปัจจุบัน ใช้มานานเท่าไหร่ น้ำหนักก่อนเริ่มยา และแพทย์แนะนำวิธีหยุดอย่างไร (หยุดเลย/ลดโดส)
6. **โรคประจำตัว / ยาอื่น** — เบาหวาน ความดัน ไทรอยด์ PCOS ฯลฯ
7. **น้ำหนักเป้าหมาย** และกรอบเวลาที่หวัง
8. **อาหารที่กินบ่อย 10 อย่าง** และสิ่งที่ไม่กิน/แพ้ — ใช้สร้างฐานข้อมูลอาหารไทยส่วนตัว
9. **ตารางชีวิต** — ตื่น/นอนกี่โมง สอนช่วงไหน มื้อไหนคุมยากสุด
10. **อุปกรณ์ที่มี** — เครื่องชั่ง นาฬิกาสุขภาพ ตาชั่งอาหาร
11. **ช่องทางที่อยากใช้** — Claude Code ในรีโปนี้ (ระยะ 1) / LINE / เว็บ
