## เมื่อเปลี่ยนเป็น Pro — ใช้แบบประหยัดโควตา
1. **ใช้แอปเป็นหลัก** ชั่ง/บันทึกไม่ใช้โควตาเลย การวิเคราะห์อาหารใช้ 1 ครั้งต่อมื้อ (มีรูปใช้มากกว่าข้อความเล็กน้อย)
2. ถ้าโควตาใกล้หมด: บันทึกมื้อด้วยช่อง "บันทึกเอง" (ใส่ kcal จากตารางใน `data/thai-foods.csv`) และใช้ "คุย" เฉพาะเมื่อจำเป็น
3. สรุปสัปดาห์ใช้ 1 ครั้ง/สัปดาห์ ที่เหลือหน้าแอปคำนวณให้เองโดยไม่ใช้โควตา
4. ถ้าการเช็กอินอัตโนมัติหยุดทำงานหลังลดแผน: ตั้งนาฬิกาปลุกมือถือ 06:40 "พิมพ์เลข" และ 21:20 "คืนนี้" แล้วเปิดแอปเอง ระบบทั้งหมดยังทำงานเหมือนเดิม

## เมื่อโค้ชต้องปรับแผน (งบ เป้า TDEE)
แก้ที่ `settings/profile` ในฐานข้อมูลแอป (โค้ชใน Claude Code ทำให้ด้วย `ArtifactData`) แอปอ่านค่าใหม่ทันที ไม่ต้องเผยแพร่หน้าใหม่
